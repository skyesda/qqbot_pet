# v3.25.5 卡片视觉修复

以旧版浏览器输出作为视觉参考，修复 v3.25.4 原生渲染中标签、数值和说明混成单行的问题。

- 修士：身份与战力左右分布，六装备围绕立绘，气血与体力并排，各属性独立面板，资源/配置/进度/情缘分别呈现；操作区恢复青绿底与金色标题。
- 菜单：恢复一整张双栏宣纸、细分隔线、独立章节编号与红色命令，不再给每个章节加一层外框。
- 背包：恢复渐变纸面、彩色 62px 线描图标、独立数量徽标与横向汇总；坐骑恢复金色战力面板，国庆贺词的主题和奖励分栏显示。
- 字体：随插件分发中文正文、粗体和宋体标题，测量与绘制使用同一字体；词云排布与绘制共用宋体，避免跨平台替换产生重叠。字体来源与授权见 assets/fonts/SOURCE.md。

仍使用 Pillow、原素材、按内容增高和图片缓存。渲染版本提升以失效旧样式缓存。6 项原生卡片测试及必需模块语法检查通过；覆盖 14 个样本和长背包完整性。实际旧菜单、背包与宠物 HTML 也已离线出图检查。此前生产性能表属于 v3.25.4，不应作为本版速度承诺。

本版需要另行授权冷重启后才能被运行中的服务加载。
