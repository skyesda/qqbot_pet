# 玩家中心布局（v3.16.6）

`/portal` 沿用官网的墨绿、米白、朱砂和仙山背景，桌面为修士角色侧栏与内容区，手机可展开角色选择。左侧只列角色，不列宠物；选中修士后，在右侧「灵宠」页切换该角色对应的宠物。仅有宠物的旧角色仍可通过其用户 ID 选择。

## 功能位置

| 入口 | 内容 |
| --- | --- |
| 总览 | 修士立绘与六件装备、修士属性、体力、战力构成、四种资源、活动冷却 |
| 灵宠 | 档案、升级/进化、宠物定制、自动助手开关与活动修改 |
| 坐骑 | 全部坐骑、定制资格、新建与更换外观、审核状态 |
| 背包 | 全量道具搜索、滚动懒加载、道具使用、神器佩戴、秘技参悟 |
| 兑换 | 当前角色的卡密兑换与结果 |

绑定角色、账号密码、退出、网页游玩、反馈与协议入口仍保留。分区切换保留表单输入；背包首次显示10项，滚动接近底部时再追加10项，保留已显示内容与道具数量输入，无翻页控件。搜索匹配完整背包，再按需显示结果；切换角色重置搜索和显示数量，同角色刷新保留展开范围。全部加载后显示结束提示，另有「加载更多」按钮作为键盘操作和不支持观察器的浏览器的备用入口。

自动助手提供「选择活动 / 修改活动」、清空重选、取消和保存。活动与上限直接来自游戏任务注册表（目前19项、最多4项），不维护前端副本。草稿只在点击保存后写入所选宠物，切换角色或宠物丢弃草稿；异步旧响应不会覆盖新宠物。保存沿用群聊规则：不自动开机，运行中的助手继续使用新活动，清空会停机。无次数仍可修改或关闭，开启需有次数或处于免费窗口。接口校验登录、CSRF、角色归属、宠物索引、活动有效性、去重及数量，不扣额度，不改执行日志。

旧响应通过请求序号隔离，避免快速切换角色时覆盖当前档案。未绑定、纯修士、加载失败状态都有明确提示。修复无宠物角色缩略图使用不存在的 `blankImg` 局部变量的问题。

## 修士立绘与装备

总览复用群聊修士图的职业、性别立绘与装备素材，中央全身立绘，左右各三件装备。每个装备位显示实际等级、按职业与进阶生成的名称、觉醒词条；未觉醒时显示明确提示。装备位固定为武器、法衣、灵印、灵冠、灵靴、玉佩，具体名称随职业变化。手机仍保持三列，完整展示立绘。

图片通过独立静态地址加载，优先使用已有 WebP；接口只返回图片地址，不内嵌图片。数据读取不修改角色存档。
