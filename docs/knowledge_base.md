## 一、插件概述

**宠物乐园** 是一个 AstrBot 群聊宠物养成 / 对战插件，复刻经典 QQ 群“宠物联盟”玩法。所有指令均为**无前缀中文指令**，插件监听群消息后自行解析路由。

核心玩法：砸蛋抽宠、宠物市场购买、宠物升级 / 进化 / 飞升 / 渡劫、属性克制对战、跨群挑战、排行榜、神器 / 秘技 / 天赋 / 炼丹、副本 / 深渊秘境 / 剧情任务、婚恋系统、限时活动、世界 Boss、管理网站、卡密系统、群授权等。

**数据按群隔离**：同一用户在不同群的宠物、金币、积分、背包、任务、婚恋等数据互相独立。`宠物排行` 仅统计本群，`宠物神榜` 为全服跨群排行。

### 4.1 成长阶段

### 4.2 品质

| 品质 | 成长系数 | 砸蛋概率 | 宠物市场可购买 |
|---:|---:|---:|:---:|
| 普通 | 1.0 | 60% | ✅ |
| 精品 | 1.4 | 19.2% | ✅ |
| 稀有 | 1.9 | 10.4% | ✅ |
| 神级 | 2.5 | 5.6% | ✅ |
| 传说 | 3.2 | 2.4% | ✅ |
| 史诗 | 4.0 | 1.28% | ✅ |
| 圣灵 | 5.0 | 0.18% | ❌（活动/定制限定） |
| 洪荒 | 6.2 | 0.15% | ❌ |
| 创世 | 7.6 | 0.12% | ❌ |
| 混沌 | 9.2 | 0.08% | ❌ |

高品质会显著影响宠物初始属性和每级成长值。圣灵及以上品质只能通过活动、卡密、品质卡等途径获得。

### 4.3 属性克制

克制关系：克制方 PK 时额外 **+50%** 战力。

- 金 → 木 → 土 → 水 → 火 → 金
- 风 → 雷 → 冰 → 风
- 光 → 暗 → 光

### 4.4 战力公式

```
战力 = (攻击+防御)×2 + 智力×1 + (生命上限×心情) + 神器加成 + 秘技加成
```

天赋加成：

- `狂暴怒火`：战斗时战力 ×1.3
- `天火御甲`：战斗时 +30% 防御，免疫负面效果
- `蝶逆轮回`：满血弱者 30% 概率秒杀高战力对手
- `神隐遁术`：被高战力攻击 50% 概率逃脱

### 5.2b 绑定QQ（强制）

宠物乐园开启「强制绑定QQ」后，**必须先绑定QQ才能游玩**，未绑定发任何游玩指令都会被拦截并提示去绑定。

- **绑定流程**：发送 `绑定QQ 123456789` → 系统向该QQ的QQ邮箱发6位验证码 → 发送 `验证码 123456` 即绑定成功。
- **跨群通用**：绑定一次，全群生效，其它群无需重复绑定。
- **绑定后好处**：可用QQ号或 `@对方` 代替用户ID（赠送/转让/PK/拜访等）。
- **换绑 / 解绑**：`换绑QQ 新QQ号` / `解绑QQ`。
- **管理员代绑**：若无法收验证码，可请**大管理员**发送 `绑定QQ @对方 你的QQ号` 代你完成绑定（免邮箱验证）。
- 若提示「邮箱服务未配置」，请联系管理员开通SMTP邮箱验证。

## 二十、群授权机制

| 状态 | 说明 |
|---|---|
| 未授权 | 本群无法使用宠物乐园 |
| 已授权 | 在有效期内可正常使用 |
| 已过期 | 需重新授权 |

授权方式：

- 大管理员：`授权本群 天数 [官方服|无限服]`（第 2 个可选参数设定服类型，省略则维持现状）
- 任何人：`授权 卡密`（卡密自带服类型）

小管理员身份随本群授权失效而消失。

### 20.1 服类型：官方服 / 无限服

每群一个「服类型」（`group["server_type"]`），默认 **官方服**，由大管理员通过 `设为无限服` / `设为官方服` 切换，或在授权时一并设定。

| 服类型 | 跨群挑战 | 宠物神榜 | 数据 | 小管理员加币/积分 |
|---|---|---|---|---|
| **官方服**（默认） | ✓ 可发起/被挑战 | ✓ 计入全服神榜 | 按群隔离（`group_id\x1fqq`） | 每日上限 `subadmin_daily_add_limit` |
| **无限服** | ✗ 双向关闭 | ✗ 不计入 | 完全群独立，不参与跨群共享层 | **无每日上限**（仍不可增减钻石） |

要点：

- 「无限服」仅从跨群功能中**剔除**（神榜源、跨群攻击发起/被挑战/随机候选、神榜前三奖励），并不改变玩家数据键控——`player` 本就按键 `group_id\x1fqq` 结构化群独立。
- 服类型不影响「群绑定」：同一物理群跨机器人 openid 归并（`group_map`）是同一群身份统一，非同群共享。
- `设为无限服` 后本群从全服神榜/跨群池中移除；`设为官方服` 恢复共享。
- 无限服小管理员虽然**无每日上限**，但仍受「只能在本群、仅金币/积分、不可增减钻石、减币不限」等约束。

## 二十三、战斗系统

### 23.1 普通对战

1. 计算双方有效战力（含属性克制）与攻击/防御数值
2. 防守方触发 `神隐遁术` 可能逃脱
3. 攻击方触发 `蝶逆轮回` 可能秒杀
4. **胜负判定：先比攻击方攻击值 vs 防御方防御值**——破防者（攻击>防御）直接取胜；
   攻击 == 防御 时，才退回比有效战力（含克制）决出胜负；攻击 < 防御 则攻击方落败
   （双方主人们当前骑乘的**坐骑战力**会并入「有效战力」一并比较，坐骑更高者在平局时占优）
5. 失败者扣血 1/3
6. 胜利方获得经验，可能击杀对方并偷取物品

### 23.2 世界 Boss

1. 每次挑战消耗精力
2. 造成伤害 = 宠物战力 × random(0.8, 1.2) × 伤害系数
3. Boss 反击对宠物造成伤害
4. 击杀后按伤害比例分配奖励
5. 进入复活倒计时，复活后全服广播

## 二十四、坐骑系统

> 坐骑是账号级的多只「坐骑」玩法：买入后无需手动骑乘，只要在**开启坐骑系统的群**里发言即**自动登场**，入场发一次积分奖励；**30 分钟无消息自动离场**；坐骑战力**计入宠物对战战力总额**。

### 24.1 指令

| 指令 | 说明 |
|---|---|
| `坐骑系统` | 玩法帮助 |
| `坐骑市场` | 在售 12 款坐骑（价格/星级/初始战力） |
| `购买坐骑 名称` | 扣积分入手坐骑，生成号牌 |
| `坐骑图鉴` / `坐骑图鉴 名称` | 全部坐骑列表 / 单只详情（已拥有渲染卡片） |
| `坐骑列表` | 已拥有坐骑清单（纯文本 Markdown，不带图） |
| `我的坐骑` | 当前骑乘坐骑详情 + GIF 图（未骑乘则提示） |
| `骑乘坐骑 名称` | 切换骑乘（无参自动骑最高档） |
| `坐骑升级` / `升级坐骑 名称` | 耗 5000 钻石，Lv+1，战力 +500~1000 随机 |
| `赠送坐骑 用户ID` | 同赠送宠物，走转让限制（大管理员豁免） |
| `丢弃坐骑 名称` | 移除坐骑 |
| `定制坐骑` | 预留说明入口（联系客服/群主，起步 100 万积分） |
| `开启/关闭坐骑系统` | 群级开关（需管理员） |
| `开启/关闭坐骑入场提示` | 玩家级入场提示开关 |
| `开启/关闭坐骑离场提示` | 玩家级离场提示开关 |

### 24.2 数据模型（`petpark.json` 玩家字段）

- `mounts`：`{坐骑名: {level, power, plate, obtained, custom}}`
- `active_mount`：当前骑乘坐骑名（"" 未骑乘）
- `mount_group`：骑乘所在群（离场推送目标）
- `mount_enter_ts` / `last_msg_ts`：入场时间 / 最后发言时间（离场判定）
- `mount_enter_notify` / `mount_leave_notify`：入场 / 离场提示开关
- 号牌：`mount_plate_seq` 全局递增（store 顶层），生成 `骑-{seq}`（自 50000 起）

### 24.3 入场 / 离场

- **入场**：开启坐骑系统的群内，拥有坐骑的用户发任意消息即自动骑乘**基础战力最高**的一只；入场**一次性**发放积分（实际到账额 `randint(reward_min, reward_max)`，**入场卡显示该实际到账数值并即时入账**），并推送「闪★亮」入场卡（提示可关）。
- **在群**：每次发言刷新 `last_msg_ts`。
- **离场**：后台每 60 秒扫描，`now - last_msg_ts ≥ 30 分钟` 且仍在场 → 清空骑乘状态，推送「绝★尘」离场卡（**离场不发奖励**），并保存。
- 已有多只坐骑可 `骑乘坐骑` 手动换乘；坐骑战力在入场后即计入对战。

### 24.4 战力与升级

- 坐骑初始战力：踏风玄鹿 1 万 → 阴阳镇世 23 万，**每名 +2 万等差**；星级 1~5。
- 升级：每次耗 **5000 钻石**，Lv+1，战力 **+500~1000 随机**，计入坐骑战力。
- 对战：`_battle` 中坐骑战力加到双方「有效战力」(`ap`/`dp`)，平局比战力时坐骑更高者胜；不影响攻击/防御破防判定。
- 展示：宠物信息卡（`_pet_card_html`）、宠物文本卡（`render_pet`）、宠物列表（`_pet_list`）、宠物侦查均把**当前骑乘坐骑战力**并入宠物「战力」，宠物信息卡额外显示「坐骑加成 +N（骑乘中）」行。
