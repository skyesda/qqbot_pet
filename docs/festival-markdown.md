# 中秋国庆活动 Markdown 展示

全部注册指令通过 `petpark/moonfest/presentation.py` 统一处理，覆盖成功、失败、未开放、次数限制、冷却和答题过程。

- 二级标题用于当前玩法；三级标题用于主题、题目进度和档案分区。
- 灯谜、玉兔同行、月饼重制、巡礼和双庆题目使用引用；提示和答题时限突出显示。
- 奖励使用粗体；档案、图鉴、排行和结算保持窄表格。
- 普通段落之间留空行，表格行之间不加空行，兼容 QQ 官方 Markdown。
- 单群献礼、里程碑通知及结算广播也使用统一排版。
- 贺词卡、祝福墙图片 Markdown 和延迟渲染标记原样返回，不破坏出图流程。
- 数值、奖励、状态写入和 Jev 审核不由展示层修改。

运行 `python tools/preview_festival_markdown.py`，在工作区 `output/festival-markdown/` 输出全部指令示例 `.md` 和重点场景的排版预览。预览为本地 Markdown 展示，QQ 实际字体由客户端决定，全部样例使用临时数据，不向真实玩家发消息。
