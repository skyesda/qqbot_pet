# 五子棋、中国象棋、军棋与围棋

四种游戏已经接入宠物乐园聊天指令、网站共用 dispatch 和 QQ 快捷按钮。它们使用独立本地规则引擎；单人对手是本地搜索 AI，不消耗聊天大模型额度。

## 开始游戏

| 操作 | 五子棋 | 中国象棋 |
|---|---|---|
| 单人 | `五子棋单人 2` | `象棋单人 2` |
| 简写 | `开始五子棋2` | `开始象棋2` |
| 邀请本群成员 | `五子棋双人 @对方` | `象棋双人 @对方` |
| 邀请用户 ID / 已绑定 QQ | `五子棋邀请 用户ID` | `象棋邀请 用户ID` |
| 落子 | `五子棋落子 h8` | `象棋落子 a7 a6` |
| 查看棋盘 | `五子棋棋盘` | `象棋棋盘` |
| 主动放弃 | `放弃五子棋` | `放弃象棋` |

`中国象棋` 可以替代所有指令里的 `象棋`。单人默认难度 1；也支持难度中文名。双人对弈没有 AI 难度。

通用指令：`棋类帮助`、`棋局`、`棋局统计`、`接受棋局`、`拒绝棋局`、`取消棋局邀请`、`认输`、`求和`、`同意和棋`、`拒绝和棋`。

邀请对象需要在任意群已有宠物乐园档案，支持用户ID或已绑定QQ跨群邀请。只有被邀请人能接受/拒绝，只有发起者能取消。棋局、邀请、计时和战绩全群共享；每个人在全群范围最多同时参与一个棋局或一个待回应邀请。换群可以查看和继续当前棋局，也可以接受邀请。无法邀请自己、抢占已有对局的玩家、替别人接受或替别人落子。

## 四档 AI

沿用扫雷名称：1 简单、2 普通、3 困难、4 地狱。棋盘大小与规则固定，难度影响 AI 策略。

| 难度 | 行为 |
|---|---|
| 简单 | 从合法候选着法随机选择，适合熟悉走法 |
| 普通 | 局面评分；五子棋优先成五、挡对手成五 |
| 困难 | 最多两层攻防搜索 |
| 地狱 | 迭代加深，最多四层搜索，更宽的五子棋候选范围 |

搜索使用 alpha-beta 剪枝，普通/困难/地狱搜索预算分别为约 0.15/0.5/1.2 秒；单个节点计算会产生少量额外耗时。达到预算时使用最后完成的一轮搜索结果，保证合法落子。这是休闲 AI 难度分级，不代表专业棋力或等级分。

## 规则与计时

- 五子棋为 15×15 无禁手规则：黑先白后，横、竖、斜连续至少五子获胜，长连也胜；满盘自动和棋。
- 象棋为 9×10：红先黑后，完整校验车、马、相/象、仕/士、帅/将、炮、兵/卒的走法，含蹩马腿、塞象眼、炮架、九宫、兵卒过河、不准送将和将帅照面。将死、困毙均判负。
- 象棋采用明确的休闲和棋约定：相同局面及行棋方出现三次，或连续 120 步（单方一步算一步）没有吃子，自动和棋；不实现专业赛事长将长捉责任裁定。
- 单人玩家和双人邀请方先行；双方看同一坐标方向，象棋黑方在上、红方在下。青色边框表示最近落点，小方框表示象棋上一步起点。
- 邀请在发出后 600 秒失效，取消邀请不记败局。
- 开局及每次合法落子后，下一方得到 600 秒。到达截止时间就判当前方放弃，对手获胜；不需要等到有人发指令才结算。
- 后台每 5 秒检查一次；任何棋类指令执行前也检查，截止边界以保存的绝对时间为准。查看、错误落子、求和、拒绝求和、普通聊天均不延时。
- 超时结果保存在对局和战绩中，下一次查看时展示；当前实现不会主动向群发一条超时消息。
- 双人可协议和棋，自己不能接受自己的求和。任何合法落子使求和请求失效。单人不接受协议求和。

## 保存与运行

运行数据保存在 AstrBot 数据目录的 `plugin_data/astrbot_plugin_petpark/boardgames.json`，使用临时文件原子替换。保存棋盘、双方、轮次、邀请、截止时间和战绩。重启后恢复活动棋局，已超过截止时间的立即结算。已完成棋局最多保留 200 局，累计战绩不丢失。

棋盘图片写入现有 `custom_images` 目录，通过现有图片服务发送；线上环境需要该服务能被 QQ 访问。图片底座和精简中文字体已随插件打包，不依赖系统安装中文字体。沿用宠物乐园的群授权和账号访问限制。战绩全群累计，按玩家、游戏、单/双人、单人难度分别记录；本次未额外添加货币或经验奖励。

开发验证：

```sh
python -m unittest discover -s tests -v
python tools/preview_boards.py
```

预览输出在 `board-previews/`。更新代码及 `petpark/assets/boards/` 后，重载插件即可启用。实际 QQ 消息投递仍需在目标机器人上验证。

## 游戏内完整说明

发送 `五子棋`、`五子棋帮助`、`五子棋介绍` 或 `五子棋指令`，展示五子棋专属完整说明。发送 `中国象棋`、`中国象棋帮助`、`中国象棋介绍` 或 `中国象棋指令`，展示中国象棋专属完整说明（均兼容“象棋”简写）。说明包含单人四档命令、双人邀请流程、落子示例、坐标方向、棋子规则、和棋/认输、10分钟时限和全群共享说明。

旧版按群保存的战绩会自动合并，迁移只执行一次；旧版同一玩家若在多个群有未结束对局，优先保留较新的兼容对局，冲突旧局取消且不计胜负。

## 军棋（双人明棋）

使用 GPT 生成的独立木质底座 `petpark/assets/boards/junqi-base.png`，沿用五子棋和象棋的暖木色、红黑棋子、坐标与青色最近一步标记。程序精确绘制公路、铁路、行营和大本营；字形随项目打包，无系统字体依赖。

- `军棋` / `军棋帮助` / `军棋介绍` / `军棋指令`：完整帮助。
- `军棋单人 1~4` / `开始军棋2`：四档本地 AI；默认简单。
- `军棋双人 @对方` / `军棋邀请 用户ID`：双人邀请。
- `军棋落子 a7 a6`：按起点、终点移动；`军棋棋盘` 查看；`放弃军棋` 认输。

本版采用固定合法布阵的明棋：双方各 25 子公开，红先黑后，坐标 a–e / 1–12。地雷位于后两排、炸弹不在前排、军旗位于本营、行营初始为空。单人玩家和双人邀请人执红，双方视角一致。

军衔从大到小为司令、军长、师长、旅长、团长、营长、连长、排长、工兵；同级交战同时移除。公路走一步，普通棋子在空铁路上直行，工兵能沿空铁路转弯；均不能越子。中央 a/c/e 三条铁路连接两军。行营斜线可走且营内棋子免受攻击；进入大本营后不能移动。军旗与地雷不可移动。

规则约定：工兵排雷存活，其他普通棋子撞雷只移除攻击者；炸弹与敌子同归于尽。军旗被吃或被炸即负，无需先排光地雷；无合法着法也判负。三次重复局面或连续 120 步未交战自动和棋。邀请、10 分钟计时、全群续局、重启恢复、求和和战绩均复用棋类系统。

规则参考：[在线军棋规则](https://www.junqi.app/zh/rules)。有不同约定的规则以本页及游戏内帮助为准。

预览：运行 `python tools/preview_boards.py`，军棋输出 `board-previews/board_junqi_1.png`。
验证：`python -m unittest discover -s tests`。

## 围棋（19 路）

沿用 GPT 生成的 `wood-base.png` 木质底座，搭配黑白棋子、九个星位、双侧坐标和青色最近落点框。图片 1000×1060，字形 `GoGlyphs.otf` 随项目打包。

- `围棋` / `围棋帮助` / `围棋介绍` / `围棋指令`：完整规则与指令。
- `围棋单人 2` / `开始围棋2`：单人；支持 1–4 或简单、普通、困难、地狱。
- `围棋双人 @对方` / `围棋邀请 用户ID`：对方发送 `接受棋局` 后开始。
- `围棋落子 d4`：列 a–s（包含 i），行 1–19；双方同向，黑先白后。
- `围棋停一手` / `围棋过`：跳过当前回合；连续两次停一手立即计分。
- `围棋棋盘`、`棋局`：当前棋盘、提子记录、轮次；`认输` / `放弃围棋`：认输。

单人玩家及双人邀请人执黑。提子按整块棋的气判定，先提敌子再检验己方气，禁止自杀。使用全局同形禁止：非停手着法不能重现本局任意已有盘面，历史随存档恢复。停手不受同形禁止限制，正常落子重置连续停手计数。

计分采用明确的盘面面积约定：在盘棋子加仅与己方接壤的空区，共同接壤或无棋子边界的空区不计，白贴 7.5 点。提掉的棋子仅作记录，不重复加分。没有自动死活裁判或死子协商：双方应先实际提掉死子、收完官子，再以连续停手确认当前盘面。游戏帮助在结算前明确提示这项约定。规则参考：[英国围棋协会规则说明](https://www.britgo.org/intro/intro2.html)、[面积计分与贴目约定](https://britgo.org/mso19x19)。

围棋使用独立的休闲 AI：简单随机选候选，普通按提子、气和棋形评分；困难检查最多 4 个候选的对手应手，地狱最多 10 个候选，分别给第二层评估约 0.5 / 1.2 秒预算。候选生成和单节点计算有额外耗时。AI 避免填明显己方眼位，并在没有候选或玩家停手且己方盘面领先时停手。它不是 KataGo 等专业引擎。

复用全群邀请、每手 10 分钟、重启恢复、求和和按棋种/模式/难度记录战绩。两次停手之外，不套用象棋的重复局面和 120 步和棋规则。

预览：`python tools/preview_boards.py` → `board-previews/board_go_21.png`。
