# v3.25.1 图片渲染优化

生产日志抽样（2026-10-03）：未命中缓存的修士/灵宠图片耗时约4～23秒，缓存命中约0.3秒。服务器约2GB内存，并存在交换区使用；此为背景信息，不能仅凭交换区使用认定单一原因。

本次修复：

- `crop_canvas` 卡片直接截图唯一顶层 `.card`/`.scroll` 的实际区域，避免截图5200px画布后裁剪。找不到唯一卡片时仍使用原画布；图片、字体加载等待保留。
- 页面关闭、崩溃、浏览器断连后在当前请求内重启重试一次；资源超时不重复等待。
- 本地渲染先启动，快速完成时不检查农场；本地偏慢时再检查农场，健康检查最长0.5秒，任务渲染原8秒超时保留。
- 农场输出改为临时文件加原子替换，与本地写图一样，不公开半写文件。
- 延迟渲染异常保留原游戏结果并返回文字提示；最终回复不使用的图片任务不再生成。任何重试都只操作图片快照，不重跑游戏奖励。

验证：`tests/test_image_renderer.py`覆盖并发同图合并、缓存失效、事件循环响应、崩溃恢复、资源超时、农场异常回退、短健康检查、原子写入、坏图片清理和游戏结果保留。

`tools/benchmark_image_renderer.py`使用已有本地修士与宠物HTML快照，在同一常驻浏览器中交替各渲染3次，比较整画布裁剪与卡片区域截图；输出尺寸和像素须完全相同。最终本地样本中位数：修士354.8→260.5ms，宠物531.8→467.3ms。此为截图阶段的本地测量，不代表生产服务器或QQ收图耗时；发布后需结合真实请求日志验证。
