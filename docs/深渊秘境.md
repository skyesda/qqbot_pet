# 🌀 深渊秘境

> **“等级门槛极低、精力消耗极低、冷却极短——但越赌越亏。”**
>
> 深渊秘境是一个面向所有玩家的**高频运气副本**。你可以无限次挑战，没有每日次数限制；但每一次进入都会加深“深渊侵蚀”，让收益递减、风险递增、成本变大。

---

## 一、基础信息

| 项目 | 设定 |
| --- | --- |
| 入口指令 | `深渊秘境` |
| 等级要求 | 宠物达到 **Lv20** |
| 精力消耗 | **动态**：首次 20，随深渊侵蚀上涨 |
| 冷却时间 | **动态**：首次 5 分钟，随深渊侵蚀上涨 |
| 次数限制 | **无限制**，但软限速会自然劝退无限刷 |
| 状态要求 | 宠物不能处于死亡、心情 1 星、饥饿等限制状态 |

---

## 二、核心机制：深渊侵蚀

每次进入深渊都会积累 **1 点深渊侵蚀**。侵蚀不会封住你的进入次数，但会从三个维度惩罚你：

### 1. 经验收益降低

```text
收益倍率 = max(0.1, 1 - 侵蚀 × 0.04)
```

| 侵蚀 | 经验收益 |
| ---: | ---: |
| 0 | 100% |
| 5 | 80% |
| 10 | 60% |
| 15 | 40% |
| 20 | 20% |
| ≥22 | 10%（封顶） |

### 2. 怪物战力提升

```text
怪物战力 = 基础战力 × (1 + 侵蚀 × 0.06)
```

| 侵蚀 | 怪物加成 |
| ---: | ---: |
| 0 | 0% |
| 5 | 30% |
| 10 | 60% |
| 15 | 90% |
| 20 | 120% |

### 3. 玩家战力浮动下限降低

```text
有效战力 = 宠物战力 × random(下限, 1.8)
下限 = max(0.3, 0.8 - 侵蚀 × 0.02)
```

也就是说，侵蚀越高，你越难 roll 出高战力，战斗失败概率越大。

## 三、动态成本与冷却

### 精力消耗

```text
本次精力 = min(80, 20 + 侵蚀 × 3)
```

| 本次是第几次 | 侵蚀 | 精力消耗 |
| ---: | ---: | ---: |
| 第 1 次 | 0 | 20 |
| 第 5 次 | 4 | 32 |
| 第 10 次 | 9 | 47 |
| 第 15 次 | 14 | 62 |
| 第 20 次 | 19 | 77 |

### 冷却时间

```text
本次冷却 = min(1800, 300 + 侵蚀 × 60)  // 单位：秒
```

| 本次是第几次 | 侵蚀 | 冷却时间 |
| ---: | ---: | ---: |
| 第 1 次 | 0 | 5 分钟 |
| 第 5 次 | 4 | 9 分钟 |
| 第 10 次 | 9 | 14 分钟 |
| 第 15 次 | 14 | 19 分钟 |
| 第 20 次 | 19 | 24 分钟 |

> 精力自然恢复为 1 点/分钟，第 10 次要等近 50 分钟才能恢复，已经天然限速。

## 四、单场事件卡

每次进入深渊只触发**一个事件**，5 分钟一把，节奏很快。

| 事件 | 概率 | 说明 | 经验倍率（相对本级升级所需经验） |
| --- | ---: | --- | ---: |
| 🗡️ 深渊守卫 | 30% | 普通战斗，战力浮动 | 0.3 倍 |
| 🎁 深渊宝箱 | 25% | 直接开箱，20% 概率是宝箱怪 | 0.2 倍（宝箱怪击败后 0.5 倍） |
| ⚡ 深渊乱流 | 15% | 随机：增益/减益/受伤/清侵蚀 | -0.1 ~ +0.3 倍 |
| 🌀 古老祭坛 | 15% | 选择献祭 15% HP 换更高收益 | 不献祭 0.2 倍 / 献祭 0.6 倍 |
| ✨ 深渊赐福 | 10% | 大奖事件，回血 + 高额经验 | 1.0 倍 |
| 👹 深渊领主 | 5% | 小 Boss，高战力要求，最高回报 | 1.5 倍 |

### 最终经验公式

```text
获得经验 = (100 + 宠物等级 × 80) × 事件倍率 × 侵蚀收益倍率
```

### 其他奖励

- **积分**：每次保底 `50 + 等级 × 2`
- **深渊结晶**：专属货币，每次 +1~3 个，可用于未来开放的“深渊商店”
- **道具**：宝箱/领主有概率掉落红药水、蓝药水、万能宝石、神器图纸等

| 结果 | 惩罚 |
| --- | --- |
| 战斗失败 | 只获得 10% 保底经验，宠物 HP -30% |
| 宝箱怪失败 | 无奖励，HP -20% |

| 深渊乱流诅咒 | 随机获得中毒/虚弱/肌饿等负面状态 |

## 七、深渊侵蚀如何恢复

既然没有每日次数上限，就要给玩家“解毒”的出口：

| 恢复方式 | 效果 |
| --- | --- |
| **自然衰减** | 每 20 分钟 -1 点侵蚀 |
| **每日 0 点** | 侵蚀清零 |
| **净化药水** | 使用 1 瓶清除 5 点侵蚀（商城/活动可获得） |
| **深渊乱流事件** | 有概率清除 2~3 点侵蚀 |

> 轻度玩家一天打 3~5 次，靠自然衰减就能维持低侵蚀；硬核玩家可以嗑净化药水继续赌，但要付出道具成本。

---

## 八、深渊怜悯（保底机制）

为防止脸黑到底，引入怜悯值：

- 每次没有触发「深渊赐福」或「深渊领主」，怜悯 +1。
- 大奖触发概率 = `基础 5% + 怜悯 × 0.5%`。
- 触发大奖后怜悯清零。

这样多刷几次总会出一次大奖；但大奖经验同样受侵蚀衰减，因此无法无限靠保底刷爆。

## 十、玩法策略

1. **新手/休闲玩家**：每天打 3~5 次，见好就收，不硬刚高侵蚀。
2. **赌徒玩家**：连刷到底等大奖，但要接受后期收益暴跌。
3. **肝帝**：囤净化药水清侵蚀后继续刷，但成本会吃掉收益。
4. **脸黑玩家**：利用怜悯机制，越刷大奖概率越高，但别在侵蚀 15 以上硬赌。

---

## 十一、设计目标

- ✅ 门槛低：Lv20、20 精力、5 分钟冷却，随时可玩。
- ✅ 高上限：单次大奖可能直接给 1~1.5 级经验。
- ✅ 反刷子：侵蚀机制让无限刷的收益自然衰减。
- ✅ 有博弈：玩家需要在“继续赌热度”和“见好就收”之间做选择。
- ✅ 有兜底：怜悯机制保证长期不至于零收益。
