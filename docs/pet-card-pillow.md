# 宠物灵鉴直接合成（v3.25.3）

固定宠物卡增加 Pillow 通道，跳过 Playwright、Chrome、DOM 布局和截图。
输入仍是已有 HTML 的不可变快照，显示数值仍由原游戏函数产生，避免双份逻辑。
从固定结构提取姓名、品质、属性、经验/仙元、气血、精力、心情、技能、神器、
坐骑、伴侣、标签和异常状态；使用原背景 WebP、原立绘和中文字体直接排版。
长内容自动换行、增高。支持实际宠物图 760px 及 900px 示例；未知结构、其他尺寸、字体或图片失败回退原浏览器。
不读取 HTML 内的公网图片和任意文件路径，立绘只接受已有嵌入 data URI。

JPEG 质量仍为 88，原子发布、精确 HTML 缓存、请求隔离和失败文本兜底保留。
仅宠物卡升级缓存版本，其他卡片继续复用现有缓存。

2026-10-03 同服务器、同一宠物 HTML 示例测试（包括 JPEG 编码）：

| 次数 | Pillow 实际耗时 | CPU 时间 |
| --- | ---: | ---: |
| 第一次 | 1410.1 ms | 912.6 ms |
| 第二次 | 882.2 ms | 649.4 ms |
| 第三次 | 616.1 ms | 405.7 ms |

另一次相同示例的浏览器阶段测试：内容加载 600.8ms，字体就绪 4.9ms，
取面板位置 298.6ms，PNG 截图 2998.8ms，JPEG 截图 1399.4ms。
浏览器包含冷启动的首次总耗时 23688.7ms；这些样本不等同 QQ 客户端收到时间，
宿主机 CPU 抢占仍影响结果。线上此前宠物卡浏览器渲染记录为 8390.9ms。

服务器中文字体及原素材的输出已人工读图验证。新增 4 项测试验证长内容、
无立绘、结构不匹配、浏览器不启动、失败回退及原子 JPEG；原渲染 10 项测试通过。

复现：

```sh
python tools/benchmark_pet_pillow.py /tmp/petpark-render-benchmark.html --output /tmp/pet-preview.jpg
```

菜单、背包、修士等复杂布局继续使用原浏览器。本次没有全面替换所有图种。
