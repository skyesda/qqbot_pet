# 游戏卡片原生渲染（v3.25.4）

内置宠物、修士六装备、坐骑、背包、地图、菜单、突破结果、国庆贺词、祝福墙与词云改用 Pillow。保留现有立绘、装备图和主题底图；通过结构化 HTML 快照读取权威数值，不重新计算游戏结果。字体、底图有界缓存，两个制图线程，同一输出合并并发请求，JPEG 88 原子写入。未知布局或原生渲染失败仍由原浏览器线程处理。
