# v3.25.6：按旧版构图恢复原生卡片

旧版宠物截图在 760px 画布上仍使用 310px 的立绘区。v3.25.5 把 900px 原生卡缩成 760px，连立绘与文字一起变小；地图通用渲染也丢失了圆形节点、路径连线与交错章节。这些属于视觉退化，不能以“已出图”作为验收。

新增 `petpark/faithful_cards.py`，由生产图片管线调用：

- 宠物按实际输出宽度布置双栏，立绘区保留 310px，属性值加粗，行间交替底色，战力金色渐变，状态独立徽标。
- 坐骑采用专用双栏档案布局，250px 立绘、金色战力、紧凑属性表。
- 地图恢复 126px 圆形地标、章节连线、反向章节、数字牌、状态色和未解锁去饱和，背景的上下渐变遮罩与原 CSS 对齐。
- 突破卡恢复 cover 底图、阶段对应主题色、光晕、圆形白底立绘区、半透明圆角结果区；先把原图放入方形图像框再应用圆形蒙版，避免把人像裁成椭圆。
- 其余卡片复用原生测量逻辑，恢复粗体书法标题、连续双栏顺序、紧凑修士标签/数值区、62px 背包图标、祝福印章和最小留白。复用采用函数私有命名空间注入专用 Painter，不修改共享模块变量，避免并发互相替换。

保留原素材、中文字体、Pillow、两线程制图、缓存、异常浏览器回退；缓存版本递增，避免命中退化样式。未知 HTML 仍交给浏览器，不把这一渲染器视为通用 CSS 引擎。

验证包括旧版真实宠物/背包/菜单 HTML、14 个内置样本、20 个地图节点和状态、长背包、长技能和超大属性值。新增测试检查 760px 输出的立绘区域不被缩小，以及长文本绘制不超出画布。对比图使用同一份宠物档案数据；仍不宣称与浏览器逐像素相同。
