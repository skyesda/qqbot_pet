> **适用版本**：v3.11.0　|　**整理日期**：2026-09-21

> **范围**：只收**「玩家能拿到东西」**的指令。纯查看类指令仅在作为入口必须提及时列出，并标注「仅查看」。

## 0. 阅读约定

| 项 | 说明 |
|---|---|
| 怎么发 | 指令无前缀，在群里直接发（例：`签到`、`历练 1`、`进入副本 幽暗森林`） |
| 前提 | 群需已授权；多数指令要求**已绑定 QQ**（配置项 `require_qq_bind` 默认开启） |
| 新旧名 | 游戏已完成「修士化」改名：面板显示修士视角名（`修士修炼` / `历练` / `灵宠修行`），**旧名多数仍可用**（`宠物→灵宠` 全表映射 `data.py:1570`）。本文以**现行名**为主，括注旧别名 |
| 货币对照 | 灵石 = 旧「金币」；玄晶 = 旧「积分」；天晶 = 旧「钻石」 |
| 修士轴新增资源 | 修为、灵材（修士本体养成）；仙元（灵宠飞升后）；深渊结晶；活动代币（每个活动各一种） |
| 「有收益」的定义 | 拿到 货币 / 经验 / 属性 / 物品 / 宠物 / 碎片 / 品质卡 / 修为 / 灵材 / 仙元 / 结晶 / 天赋 中任意一项 |
| 时间基准 | 冷却与「每日」均按**北京时间**，跨天以自然日 0 点为界 |
| 指人方式 | 多数指令可直接写「用户ID」，也可 @对方（框架自动解析） |

**一句话版**：想拿资源，日常靠「签到 + 十个日常动作 + 自动助手」；想拿宠物，靠「砸蛋 + 炼化 + 碎片合成」；想拿修为灵材，靠「历练 / 副本 / 秘境 / 讨伐首领」；想拿仙元，必须先把灵宠**飞升**。

## 一、每日产出：日常动作与修炼

### 1.1 十个日常动作（`data.py:1515-1529`，实现 `main.py:10668-10759`）

**公共机制**（对全部 10 个动作生效）：

- **冷却**：每次执行后设 `日常:<动作>` 冷却，`randint(600,1200)` 秒 = **10~20 分钟随机**；每个动作**各自独立冷却**（`main.py:10693-10695`）
- **无每日次数上限**：只限速，不限次（代码中不存在对日常动作的日限校验）
- 前置：要有宠物；宠物**死亡 / 假死惊魂 / 心情 ≤1★** 时被拦（`_busy_reason`，`main.py:9344-9356`）
- **玩耍豁免心情门槛**（唯一能回心情的动作，否则心情 1★ 会锁死，`main.py:10672-10674`）
- 灵宠**已飞升**后，`修炼 / 双修` 被禁，须改用仙元玩法（`main.py:10683-10684`）

| 指令（别名） | 精力 | 实际获得 | 前置 / 注意 | 位置 |
|---|---|---|---|---|
| **约会**（道侣之约） | 10 | 好感度 `+(5 + 等级//5)`；**已婚翻倍**；若已缔结道侣，**对方灵宠同样 +等量好感** | 上限 999999；对上限后不再增长 | `main.py:10697-10710` |
| **修炼**（灵宠修行） | 10 | 经验 `randint(50,120) + 等级×15` | **已婚者被禁**（改用双修） | `main.py:10711-10714` |
| **双修**（道侣双修） | 20 | 同公式**×2 倍**经验 | 必须已婚 | `main.py:10711-10716` |
| **打工** | 10 | **玄晶** `randint(200,600) + 等级×5` | — | `main.py:10722-10725` |
| **闭关** | 5 | 血量回满 | 不加属性 | `main.py:10726-10728` |
| **学习** | 10 | **智力 +`randint(3,10)`** | — | `main.py:10729-10732` |
| **玩耍** | 5 | **心情置满 ★★★★★** | 唯一能回心情的动作 | `main.py:10733-10735` |
| **洗髓** | 15 | 智力 `-conv`，**攻击或防御 +`conv×2`**（各 50%）；`conv = randint(10, max(11, 智力//3))` | 需智力 > 20（否则拒绝，**且被拒也会白扣 15 精力并进冷却**，见 §10.1） | `main.py:10736-10745` |
| **探险** | 20 | 见 §1.2 探险奖励表 | 25% 空手（天赋「鸿运当头」免疫空手） | `main.py:10746-10747` |
| **冥想** | 30 | **随机一项永久属性 +`randint(50,200)`**（攻击/防御/智力/生命上限 四选一，等概率） | **必须是定制宠物** | `main.py:10748-10758` |

### 1.3 自动助手（挂机代跑日常，`main.py:895-1500`）

把「自动修炼」升级而来：**玩家勾选最多 4 个任务，助手在后台按顺序全跑**，每个成功执行的任务扣 **1 次**额度。

| 指令 | 作用 |
|---|---|
| **自动助手**（`自动修炼`） | 打开勾选面板（可点按钮，也可发 `助手选 N`） |
| **助手选 `<N>`** | 切换第 N 个任务的勾选（N=1..19，见下表顺序）；**最多 4 个**，第 5 个会被拒绝 |
| **助手确定** | 把待选写入该宠物配置；勾选为 0 时无法开启 |
| **助手清空** | 清空待选 |
| **助手状态**（`自动修炼状态` / `修炼状态`） | 勾选 / 剩余次数 / 累计执行 / 最近 20 条执行日志 |
| **开启自动助手** / **关闭自动助手** | 开机 / 停机（停机保留勾选） |
| **助手卡 `<卡密>`** | 兑换自动助手卡：**1 张 = +500 次**，可叠加 |

**计费模型**（与旧版「天数卡」完全不同）：

| 项 | 规则 |
|---|---|
| 额度归属 | **玩家级**：同一玩家在本群的所有宠物共享一个次数池（`player["assistant"]["quota"]`） |
| 扣次粒度 | **每成功执行 1 个任务扣 1 次**（不是每天、不是每小时） |
| 开机条件 | 该宠物勾选非空 **且** 玩家额度 > 0 |
| 额度归零 | 自动停机（`enabled` 置回 False），需再兑换助手卡 |
| 定制宠物 | **不再永久免费、不赠送次数**，与普通玩家一致 |

**19 个可选任务**（即 `助手选 N` 的 N，`data.py` 的 `ASSISTANT_TASKS`）：

| N | 任务 | N | 任务 | N | 任务 | N | 任务 |
|---|---|---|---|---|---|---|---|
| 1 | 修炼/双修 | 6 | 深渊秘境 | 11 | 学习 | 16 | 家园收取 |
| 2 | 进入副本 | 7 | 神仙劫 | 12 | 洗髓 | 17 | 约会 |
| 3 | 挑战神仙 | 8 | 砸蛋 | 13 | 探险 | 18 | 修士修炼 |
| 4 | 外出历练 | 9 | 砸蛋十连 | 14 | 冥想 | 19 | 修士突破 |
| 5 | 秋冬Boss | 10 | 打工 | 15 | 幻境寻宝 | | |

**后台每 30 秒扫描一次**（`main.py:1397` `_assistant_tick`）：

1. 遍历所有玩家 → 所有宠物，跳过未开机 / 在死亡冻结等忙碌态的；
2. 按勾选顺序逐项做**前置谓词判定**（冷却、精力、飞升/等级/已婚等硬门槛），**只有判定能跑的才执行并扣 1 次**；
3. 执行结果**不在群里发言**（避免每 30 秒刷屏），写进该宠物的环形日志（最近 20 条），玩家用 `助手状态` 查看；
4. 额度中途归零立即停机。

> 数值沿用各玩法**手动执行的同一套公式与冷却**，助手只是替玩家点，不额外加成也不打折。
> 面板任务是**按宠物**配置的（每只宠物独立一套 4 个），但额度是**玩家共享**的——同玩家两只宠物都开机时会互相消耗同一个池子。
> 「修炼」任务会按该宠物的 `love_state` 自动选 **双修**（已婚）或 **修炼**。

> ⚠️ **消耗速率**：勾了「砸蛋」（3 分钟冷却、零精力）这类高频任务时，单宠物一天可烧掉 500~1500 次，**1 张 500 次卡可能不到一天就用完**。定价时请按此复核。

**面板按钮是回调按钮**（`action.type=1`）：点击只推 `INTERACTION_CREATE` 事件，**不会在群里冒出「@机器人 助手选 3」的玩家消息**。这是全仓库唯一使用回调按钮的地方（其它键盘仍是指令按钮 `type=2`），依赖框架的 `on_interaction_create` + intent `1<<26`；互动事件不带群成员身份，所以助手面板上**不能挂管理类指令**。

### 3.1 砸蛋（拿宠物 / 碎片）

| 指令（别名） | 获得 | 消耗 | 冷却 |
|---|---|---|---|
| **砸蛋** | 随机品质 `{品质}碎片` ×1~2；**额外 15% 掉「宠物卡」×1** | **无货币消耗** | 180 秒 |

**卡的用法（这才是「获得宠物/升品质」的关键）**：

| 用法 | 效果 |
|---|---|
| **使用 `{品质}卡 召唤`** | 消耗 1 张，**随机物种**、**该卡品质**的新宠物（需空余席位） |
| **使用 `{品质}卡 <宠物名>`** | 把已有宠物**品质直升**到该卡品质，属性按成长系数比例**整体重算**（不可降级、同品质无效） |
| **使用 变种卡 `<宠物种类>`** | 改变品种，保留等级/品质/属性；**必须写明品种，不能随机** |
| **使用 宠物卡** | 随机品质 + 随机物种的新宠物 |

> ⚠️ `购买宠物 九尾狐` 这类「按物种直购」**已下线**：`data.py:223` 的物种价表（15000~300000）全仓库零引用，是死配置。README 与 `docs/knowledge_base.md` 仍写着旧玩法。

### 8.4 关键子机制

**派遣加成** = `1 + 宠物等级×0.006 + 品质档位×0.04 + (属性匹配 ? 0.10 : 0)`
→ 例：Lv100 混沌金系宠驻灵石矿 = **×2.06**（品质档位：普通 0 … 混沌 9）

**家园防御** = `哨塔等级×25 + Σ(派遣宠物等级×0.5)`

**偷菜**：
- 成功率 = `攻击者出战宠物等级 / (该等级 + 目标防御 + 50)`
- 可偷基数 = 目标各建筑 `产量/时 × min(已累积, 上限)`（该建筑累积 <300 秒则跳过）
- 成功：偷得基数 ×`uniform(0.10,0.30)` 的灵石与玄晶，**目标账户余额另扣被偷额的一半**
- 失败：自己 −50 灵石，对方 +50 灵石
- 对方用「护院符」期间完全不可偷

**随机事件**（收取时抽，权重合计 100）：天降横财 ×3.0(3) / 丰收 ×2.0(8) / 流浪商人(10) / 宠物帮忙（额外 `总量×0.08×宠物等级/100`）(10) / 幸运日 +50~300 灵石(12) / 地脉涌动 再 ×1.3(8) / 正常(35) / 小偷 ×0.7(8) / 暴风雨 ×0.5 且下次 +50%(6)。**祈福坛**每级把好事件权重 ×(1+3%×lv)、坏事件 ×(1−3%×lv)。

**流浪商人**（抽中该事件时出现，随机 3 件货）：

| 物品 | 价格 | 功效 |
|---|---|---|
| 建筑加速券 | 2000 灵石 | 所有建筑累积前推 2 小时 |
| 护院符 | 3000 灵石 | **12 小时免疫偷菜** |
| 双倍券 | 5000 灵石 | 下次收取产量 ×2 |
| 进化神石 / 万能宝石 / 神器图纸 / 史诗卡 / 小精力瓶 / 进化神石×3 | 5000 / 3000 / 20000 / 50000 / 1000 / 12000 灵石 | 直接进背包 |
| 普通经验书 / 聚灵丹 / 相思豆×5 | 3000 / 200000 / 2000 玄晶 | 直接进背包 |

**隔离规则**：官方服**跨群共享**（同一 QQ 所有群共用一份家园，排行榜是全服的）；无限服**按群隔离**。切换服类型时数据自动迁移。

### 10.3 机制上值得注意 / 疑似缺陷

| 项 | 说明 |
|---|---|
| **家园周榜永远为空** | `weekly_coin` 只有默认值、读取与周一重置，**全仓库没有任何地方累加**（收取只累加 `total_coin_earned`）→ 周榜恒空，只有「家园总排行」有真实数据（`main.py:16580/16594/16659`，**已核实**） |
| **悟性点池上限不强制** | `min(200, 10+境界×5)` 只用于打印，加点分支不校验上限 |
| **魔修** | 代码可选且指令接受，但**玩家菜单没列**，描述里的「攻击汲取生命」**没有实现** |
| **组队不加成奖励** | 人数只放大 Boss 生命（×人数），每人各拿一份完整奖励；三人队 = 一次开战三人各一份（效率最高） |
| **世界首领没有伤害榜奖励** | 只有固定的讨伐（每次灵材+3）与击杀（灵材+12）奖励，不按名次发奖 |
| **合成类与「经验换仙元」无每日上限** | 碎片转卡/合成卡/合成材料/经验换仙元全部不限次（只受持有量限制） |
| **日常动作只有冷却、没有日限** | 10 个日常动作不限次；`历练/组队/仙途深渊` 共享每日 8 次，`试炼秘境` 另有独立 2 次 |
| **本群排行无领奖** | 只有全服前三能领天晶；无限服群不参与全服榜 |
| **棋类没有奖励** | 围棋/军棋/斗兽棋/五子棋只记胜负，赢了也没有任何实物 |
| **扫雷无每日上限** | 只限「同时一局」，未找到日限代码 |
| **`TOMB_DAILY_FREE = 3` 已废弃** | 标注「保留兼容」，无引用点；摸金入场实际只受冷却+精力+棺椁令+等级限制 |
