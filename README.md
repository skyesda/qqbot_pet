# 宠物乐园（astrbot_plugin_petpark）

AstrBot 群聊宠物养成 / 对战插件。指令全部为**无前缀中文指令**，
插件监听群消息后自行解析路由；命中宠物指令时会拦截该消息（不再走 LLM），否则放行正常聊天。

## 安装

将本目录放入 AstrBot 的 `data/plugins/astrbot_plugin_petpark/`，在 WebUI 插件管理处重载即可。
无第三方依赖。数据保存在 `data/plugin_data/astrbot_plugin_petpark/petpark.json`。

## 完整指令列表

> 群内直接发送，无需前缀。需指定对方时直接填用户ID，**绑定QQ后也可 `@对方` 代替用户ID**；指定用户在本群不存在会提示「不存在」。
>
> **兼容 `/` 前缀与官方指令面板**：QQ 官方「指令面板」点击项会自动补 `/` 前缀（如 `/签到`），插件已兼容，`/签到` 与 `签到` 等价；也支持手输 `/指令 参数`。
>
> **强制绑定QQ**：开启后所有玩家须先绑定QQ（发送 `绑定QQ 你的QQ号` → 邮箱收验证码 → `验证码 123456`）才能游玩，未绑定会被拦截并引导去绑定；`绑定教程` 查看完整说明。
>
> **数据按群隔离**：同一用户在不同群的宠物、金币、积分、背包、任务、婚恋等数据互相独立。`宠物排行` 仅统计本群，`宠物神榜` 为全服跨群排行。在群里先发送「宠物乐园」即可查看完整指令菜单（图片版）。

### 菜单 / 帮助
- `宠物乐园` — 查看完整指令菜单（一张古典羊皮纸风格图片；内容未变会一直缓存同一张图）

### 个人信息
- `我的信息`（别名 `个人信息`）— 查看 QQ号 / 群号 / 金币 / 积分 / 钻石（货币仅在此处展示；钻石初始数量可在配置面板设置，后续用于商店）
- `绑定QQ 你的QQ号` — 绑定QQ号（向该QQ邮箱发验证码），**开启强制绑定时未绑定无法游玩**
- `验证码 123456` — 输入邮箱收到的6位码，完成绑定
- `换绑QQ 新QQ号` / `解绑QQ` — 更换 / 解除已绑定QQ号
- `绑定教程` — 查看绑定QQ完整教程
- 大管理员可代绑：`绑定QQ @对方 目标QQ号` 或 `绑定QQ 用户ID 目标QQ号`（免邮箱验证）
- `签到` — 每日签到随机得积分/金币，显示今日第几位签到、累计签到天数、连续签到额外金币与当前称号（积分/金币随机范围可在配置面板调整）
- `兑换 卡密`（别名 `卡密兑换 卡密`）— 使用卡密充值金币/积分/钻石；卡密在管理网站批量生成，一次性、用过作废

### 管理网站（卡密 + 数据库管理）
- 插件启动时会在配置的端口开启网页后台（默认 `http://服务器IP:7799`），登录账号/密码默认 `admin` / `2468080asd`（可在配置面板修改）。
- 功能：查看并增删改查全部数据库（玩家 players / 群设置 groups / 卡密 cards）、批量生成卡密（金币/积分/钻石）。
- 外网访问需在云服务器安全组/防火墙放行该端口；仅本机访问可把监听地址设为 `127.0.0.1`。

### 服类型（官方服 / 无限服）
- 每群一个「服类型」，默认 **官方服**。大管理员可随时切换：
  - `设为无限服` — 本群退出跨群共享层：**不计入宠物神榜**、**不能发起也不能被跨群挑战**、所有共享玩法（家园/家园排行、摸金、扫雷、口令抽奖、生辰盛典、Boss全服伤害排行）均按群独立，不与官方服/其它无限服群共享；本群小管理员**加金币/积分无每日上限**（仍不可增减钻石）；群内**转让/赠送不设限制**（不收税、不限次数、不限单次数量）。
  - `设为官方服` — 恢复参与跨群共享层。
- 授权时也可选定服类型：`授权本群 天数 [官方服|无限服]`、或兑换带服类型的授权卡 `授权 卡密`（官方服/无限服授权卡在管理后台分别生成）。

### 点歌（QQ官方语音）
- `点歌 歌名` — 搜索歌曲并列出结果（每 10 个一页，可 `下一页` / `上一页` 翻页）
- `选歌 序号` — 按列表左侧序号用 QQ 官方语音接口发送语音条
- 依赖：需配置 `alapi_token`（ALAPI 密钥，默认已填）；服务器 venv 需安装 `graiax-silkcoder`（自带 ffmpeg 转码，无需外部二进制）并配置 `silk_url_base`（公网可拉取 silk 地址）。
- 说明：ALAPI 搜索为单窗口（默认取 50 首本地翻 5 页）；部分 VIP 曲目无试听资源会提示换一首。

## 核心数值

- 战力 = 攻击×3 +（智力+防御)×2 +（生命×心情) + 武器加成 + 秘技加成
- 属性克制（克制方 PK 额外 +50% 战力）：金→木→土→水→火→金；风→雷→冰→风；光→暗→光
- 成长阶段：幼年期→成长期→成熟期→完全体→究极体→超究极体→飞升→渡劫
- 等级上限：超究极体及以前 Lv120；飞升 Lv220；渡劫 Lv999；满 60 级可进化（攻防翻倍、等级重置）
- 精力每分钟自动恢复 1 点（觉醒「事半功倍」天赋则 2 倍）

## 棋类玩法

新增五子棋 / 中国象棋 / 军棋（双人明棋）：单人四档 AI、双人定向邀请、每步 10 分钟超时判放弃，棋局、邀请与战绩全群共享，换群可续局。发送 `五子棋`、`中国象棋` 或 `军棋` 查看各自完整说明；`棋类帮助` 查看大厅，或直接发送 `五子棋单人 1` / `中国象棋双人 @对方`。[完整说明](docs/棋类对弈.md)。

扫雷棋盘已使用 GPT 生成的深青绿金边底座，配合圆角格子、独立坐标区、时间/雷数/进度卡片和进度条。四档尺寸均支持，保留原扫雷规则；运行 `python tools/preview_minesweeper.py` 查看预览。[素材与生图提示词](petpark/assets/boards/PROMPTS.md)。
