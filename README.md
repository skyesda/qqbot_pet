# 灵契仙途

修士职业与灵宠伙伴并肩作战的 QQ 群聊游戏。

新版发送 `灵契仙途`，依次体验 `踏入仙途 剑修` → `修士修炼` → `历练 1` → `锻造 灵剑`。三职业、20 张地图（普通/困难）、3 个组队秘境、每日轮换世界首领、5 层深渊、无损切磋均已接入。修士拥有完整属性面板（性命/攻击/防御/速度/战力 + 悟性/根骨），可用 `道号 名字`（首改免费）与 `性别 男/女`（消耗变性丹）自定义；玄晶/天晶商城新增修为丹、属性丹、悟道丹、炼体丹等修士养成道具。玩法和验证边界见 [灵契仙途说明](docs/灵契仙途.md)。

新游与旧宠物指令已合并为一张菜单，发送 `灵契仙途` 查看完整指令菜单图。内部插件标识和存档目录保持不变。

AstrBot / SkyeBot 兼容插件。指令全部为**无前缀中文指令**，
插件监听群消息后自行解析路由；命中宠物指令时会拦截该消息（不再走 LLM），否则放行正常聊天。

## 安装

将本目录放入 AstrBot 的 `data/plugins/astrbot_plugin_petpark/`，在 WebUI 插件管理处重载即可。
无第三方依赖。数据保存在 `data/plugin_data/astrbot_plugin_petpark/petpark.json`。

## 完整指令列表

> 群内直接发送，无需前缀。需指定对方时直接填用户ID，**绑定QQ后也可 `@对方` 代替用户ID**；指定用户在本群不存在会提示「不存在」。
>
> **兼容 `/` 前缀与官方指令面板**：QQ 官方「指令面板」点击项会自动补 `/` 前缀（如 `/签到`），插件已兼容，`/签到` 与 `签到` 等价；也支持手输 `/指令 参数`。
>
> **强制绑定QQ**：开启后所有玩家须先绑定QQ（发送 `绑定QQ 你的QQ号` → 邮箱收验证码 → `验证码 123456`）才能游玩，未绑定会被拦截并引导去绑定；`绑定教程` 查看完整说明。
>
> **数据按群隔离**：同一用户在不同群的宠物、灵石、玄晶、背包、任务、道侣等数据互相独立。`仙途战力榜` 仅统计本群，`仙途战力榜全服` 为全服跨群排行（旧名 `宠物排行`/`宠物神榜` 仍可用）。在群里先发送「灵契仙途」即可查看完整指令菜单（图片版）。

### 管理网站（卡密 + 数据库管理）
- 插件启动时会在配置的端口开启网页后台（默认 `http://服务器IP:7799`），登录账号/密码默认 `admin` / `2468080asd`（可在配置面板修改）。
- 功能：查看并增删改查全部数据库（玩家 players / 群设置 groups / 卡密 cards）、批量生成卡密（灵石/玄晶/天晶）。

### 服类型（官方服 / 无限服）
- 每群一个「服类型」，默认 **官方服**。大管理员可随时切换：
  - `设为无限服` — 本群退出跨群共享层：**不计入仙途战力榜全服**、**不能发起也不能被跨群挑战**、所有共享玩法（家园/家园排行、摸金、扫雷、口令抽奖、生辰盛典、Boss全服伤害排行）均按群独立，不与官方服/其它无限服群共享；本群小管理员**加灵石/玄晶无每日上限**（仍不可增减天晶）；群内**转让/赠送不设限制**（不收税、不限次数、不限单次数量）。

- 授权时也可选定服类型：`授权本群 天数 [官方服|无限服]`、或兑换带服类型的授权卡 `授权 卡密`（官方服/无限服授权卡在管理后台分别生成）。

### 点歌（QQ官方语音）
- `点歌 歌名` — 搜索歌曲并列出结果（每 10 个一页，可 `下一页` / `上一页` 翻页）
- `选歌 序号` — 按列表左侧序号用 QQ 官方语音接口发送语音条
- 依赖：需配置 `alapi_token`（ALAPI 密钥，默认已填）；服务器 venv 需安装 `graiax-silkcoder`（自带 ffmpeg 转码，无需外部二进制）并配置 `silk_url_base`（公网可拉取 silk 地址）。
- 说明：ALAPI 搜索为单窗口（默认取 50 首本地翻 5 页）；部分 VIP 曲目无试听资源会提示换一首。
- 时长：QQ 官方语音单条有上限（默认 4 分钟 / 240 秒，可在配置面板 `song_max_seconds` 调整）。选中歌曲超过该时长会自动拆成多段语音依次发出并提示段数。

## 核心数值

- 战力 = 攻击×3 +（智力+防御)×2 +（生命×心情) + 武器加成 + 秘技加成
- 属性克制（克制方 PK 额外 +50% 战力）：金→木→土→水→火→金；风→雷→冰→风；光→暗→光
- 成长阶段：幼年期→成长期→成熟期→完全体→究极体→超究极体→飞升→渡劫
- 等级上限：超究极体及以前 Lv120；飞升 Lv220；渡劫 Lv999；满 60 级可进化（攻防翻倍、等级重置）
- 精力每分钟自动恢复 1 点（觉醒「事半功倍」天赋则 2 倍）
