# 宠物乐园（astrbot_plugin_petpark）

AstrBot 群聊宠物养成 / 对战插件。指令全部为**无前缀中文指令**，
插件监听群消息后自行解析路由；命中宠物指令时会拦截该消息（不再走 LLM），否则放行正常聊天。

## 安装

将本目录放入 AstrBot 的 `data/plugins/astrbot_plugin_petpark/`，在 WebUI 插件管理处重载即可。
无第三方依赖。数据保存在 `data/plugin_data/astrbot_plugin_petpark/petpark.json`。

## 完整指令列表

> 群内直接发送，无需前缀。需指定对方时**直接填用户ID/QQ号（不支持 @）**；指定用户在本群不存在会提示「不存在」。
>
> **数据按群隔离**：同一用户在不同群的宠物、金币、积分、背包、任务、婚恋等数据互相独立。`宠物排行` 仅统计本群，`宠物神榜` 为全服跨群排行。在群里先发送「宠物菜单」也可随时查看完整指令。

- `宠物菜单`（别名 `宠物指令`、`宠物帮助`）— 显示完整指令菜单

- `我的信息`（别名 `个人信息`）— 查看 QQ号 / 群号 / 金币 / 积分（金币积分仅在此处展示）

### 副本 / 剧情（进入副本冷却 10 分钟）

- 进入后与怪物对战：自身战力 ≥ 怪物战力即「大胜」获得经验/积分，否则「惨败」无奖励。
- **经验满后自动一键升级**：修炼/双修、副本通关等获得经验后，若已够升级会自动连续升级（消耗精力）。

## 核心数值

- 战力 = 攻击×3 +（智力+防御)×2 +（生命×心情) + 武器加成 + 秘技加成
- 属性克制（克制方 PK 额外 +50% 战力）：金→木→土→水→火→金；风→雷→冰→风；光→暗→光
- 成长阶段：幼年期→成长期→成熟期→完全体→究极体→超究极体→飞升→渡劫
- 等级上限：超究极体及以前 Lv120；飞升 Lv220；渡劫 Lv999；满 60 级可进化（攻防翻倍、等级重置）
- 精力每分钟自动恢复 1 点（觉醒「事半功倍」天赋则 2 倍）
